# 灵动搜题 (QuizIsland) — iPhone 15 灵动岛免跳端 AI 搜题助手

专为 **iPhone 15 (iOS 17+)** 打造的后台静默搜题工具。刷题时触发快捷指令，**100% 停留在当前做题 App 前台，绝不跳端**，直接通过灵动岛实时展示 **DeepSeek（主力）/ Kimi / 通义千问 / 豆包** 网页版的免费联网解答。

---

## 一、 核心亮点
1. **彻底告别快捷指令跳转**：通过 `AppIntents` 的 `openAppWhenRun = false` 协议接收屏幕 OCR 文本，系统在后台静默完成提问，无需手动切换 App、无需手动点发送。
2. **白嫖网页端 + 国内直连多引擎**：默认主推 **DeepSeek 网页版**（自动激活“联网搜索”开关），同时内置 **Kimi、通义千问、豆包** 国内直连切换入口，回国也能无缝使用。
3. **灵动岛原生分页阅读器**：针对 iOS 灵动岛无法上下滚动的限制，内置【上一页 / 下一页】原生交互按钮，长按灵动岛即可像翻书一样看完完整解析，全程不离开做题界面。
4. **Windows 零 Mac 云端自动打包**：内置 GitHub Actions 流水线，上传代码即自动在云端 macOS 编译生成 `.ipa` 安装包。

## 二、 Windows 电脑云端打包与安装步骤（全程免费）

### 第 1 步：上传代码到 GitHub 生成 `.ipa`
1. 登录 [GitHub](https://github.com)，点击右上角 `+` -> `New repository`，创建一个新仓库（例如命名为 `QuizIsland`，公开或私有均可）。
2. 将本文件夹内的所有文件上传到该仓库根目录（确保 `.github/workflows/build.yml` 和 `project.yml` 都在仓库里）。
3. 点击仓库顶部的 **Actions** 标签页，你会看到 `Build Unsigned iOS IPA` 正在自动运行（约 3~5 分钟变成绿色对勾 ✅）。
4. 点进该运行记录，在页面最下方的 **Artifacts** 区域点击 **`QuizIsland-iOS17-Unsigned`** 下载压缩包，解压后即可得到 `QuizIsland.ipa`。

### 第 2 步：在 Windows 上侧载安装到 iPhone 15
1. 在 Windows 电脑下载并安装免费签名工具 **[Sideloadly](https://sideloadly.io/)**（需确保电脑已安装 iTunes 或 Apple Devices 驱动）。
2. 用数据线将 iPhone 15 连接到电脑，手机上点击“信任此电脑”。
3. 打开 Sideloadly，把 `QuizIsland.ipa` 拖进去，在 `Apple ID` 栏输入你的个人 Apple 账号，点击 **Start**。
4. 安装完成后，在 iPhone 上打开 **设置 -> 通用 -> VPN与设备管理**，点击你的 Apple ID 信任该应用。

## 三、 iPhone 首次使用与“零跳端”快捷指令配置

1. **首次登录 AI 账号**：
   打开手机上的「灵动搜题」App，在首页内嵌网页中登录你的 **DeepSeek** 账号（也可在顶部切换 Kimi / 通义千问 / 豆包）。登录一次后 Cookie 会永久保存在本地，以后无需重复登录。
   *(注：每次准备开始长时间刷题前，建议先打开一下「灵动搜题」让它留在后台即可。)*

2. **创建“零跳端”快捷指令（核心 4 步）**：
   * 打开 iPhone 自带的 **快捷指令** App，点击右上角 `+` 新建，名字改为 **`搜题`**。
   * 添加动作 1：**拍摄屏幕快照**。
   * 添加动作 2：**从图像中提取文本**（将“图像”变量选为上一步的“屏幕快照”）。
   * 添加动作 3：搜索“灵动搜题”，选择 **后台静默搜题**：
     * 将“题目文本”填入上一步提取的“文本”；
     * 点击该动作右侧的小箭头 `>`，**关闭「运行时显示」**（非常关键，关闭后全程无弹窗干扰）。

3. **神级无感触发方式（推荐）**：
   * 方式 A：刷题时直接说 **“嘿 Siri，搜题”**。
   * 方式 B（更隐蔽更快）：打开 iPhone **设置 -> 辅助功能 -> 触控 -> 轻点背面**，将「轻点两下」设为运行 **`搜题`** 快捷指令。刷题时手指敲两下手机背面，2~4 秒后灵动岛直接弹出答案！
